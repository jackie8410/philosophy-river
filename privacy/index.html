隐私与 Cookie

网站在浏览器本地存储收藏和阅读进度，可在收藏页清除。站内搜索在浏览器中匹配公开目录。搜索页通过地址传递搜索词，地址可能进入浏览器历史及托管方的访问处理。

站点托管由 GitHub Pages 提供。访问外部书目、来源与公开纠错区时，由目的站点处理相应请求。反馈内容在 GitHub Issues 上公开，请避免提交个人联系信息。

当前部署关闭第三方广告、统计和自动视频嵌入。GitHub 的数据处理说明见 GitHub 隐私声明。
