怎样少一点自我消耗

当评价、欲望和比较占据注意力，怎样把判断重新带回自己的生活？

带着这个问题阅读

记录一次具体的比较。它描述的是可观察的事实，还是给自己设定的要求？把两个答案分开，再比较不同作者怎样理解需要、自由和关怀。

阅读顺序

  1. 庄子

    把自己置于不同尺度下，考察何种评价塑造了选择。

    生平与思想 →现代意义与启发 →

  2. 伊壁鸠鲁

    把几个实际欲望写下来，比较它们对生活安定和友谊的影响。

    生平与思想 →现代意义与启发 →

  3. 伯特兰·罗素

    比较被竞争占据的时间和能够培养广泛兴趣的时间。

    生平与思想 →现代意义与启发 →

  4. 卡伦·霍妮

    先区分具体处境造成的不安，与对自我施加的僵硬要求。

    生平与思想 →现代意义与启发 →

  5. 弗里德里希·尼采

    选一个视为理所当然的评价，追问它来自哪些生活方式和历史实践。

    生平与思想 →现代意义与启发 →

  6. 巴鲁赫·斯宾诺莎

    记录一种情感怎样产生，再读情感、原因与行动能力的关系。
