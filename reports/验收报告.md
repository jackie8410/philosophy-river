构建和单元测试可分别通过 `npm run build`、`npm run validate` 与 `npm test` 复现。本机导入后将 `PHILOSOPHY_PREVIEW_QA` 设为 `1`，可追加运行受保护预览的 HTTP 测试。上线实验使用 [GitHub Pages 实际地址](https://jackie8410.github.io/philosophy-river/)。
