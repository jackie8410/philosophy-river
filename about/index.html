关于与联系

《世界哲学与思想者长河》以人物、时间与现实问题组织中文阅读资料。每位人物的两篇文章分别提供历史语境、主要思想与现代阅读线索。

站点由 GitHub 账号 jackie8410 的项目仓库维护，托管于 GitHub Pages。

联系与纠错

可用项目的公开 GitHub Issues 反馈错误、补充来源和报告功能问题。页面上的纠错入口会带入网页地址。请在反馈中填写小节或段落，以及可核对的资料出处。
